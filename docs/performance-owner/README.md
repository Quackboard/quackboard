# Performance updates (owner-facing)

This folder is for **non-technical summaries** of performance work, so the app owner (and stakeholders) can see **what changed and why** without reading code or PR diffs.

| File | Purpose |
|------|--------|
| [CHANGELOG.md](CHANGELOG.md) | Running log + template: copy sections to email/Slack after each task. |

Contributors: add a new entry to **CHANGELOG.md** when a performance task lands on `perf/integration` (or when you brief the owner).
